# Base-converter

## Why did I make it

We just started to learn about binary in scool, I knew the generel way of expressing number and some hex to,
so I made this program as an exercise for myself.  
I wanted to improve at writing coding and also make something practical (to show the teachers too).  
I also wanted to get better at designing a good user experience.

## What dose it do

* It can decode any number with a base bigger than 1

* It can incode any number from base 10 to a base bigger than 1

* It can convert numbers form one base to any other base

## How to use

1. Download the files

2. Run the .exe file

## Tools

I used pyinstaller to make the exe
